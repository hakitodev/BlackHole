# BlackHole

Discord-бот на Node.js: экономика, магазин, модерация и сайт с настройками.

## Что умеет

- Экономика: `/collect daily|work|crime` `/bal` `/rob` `/pay` `/flip` `/dep` `/with` `/btc` `/biz` `/job` `/top` `/profile`
- Магазин: `/shop` `/buy` `/inv` `/box`
- Развлечения: `/8ball` `/roll` `/pick`
- Сервер: `/ping` `/avatar` `/user` `/server` `/help` `/settings`
- Мод: `/mod` `/give` `/take` `/authpanel` `/clear` `/slowmode`
- Сайт: ивенты, эмбеды, магаз, работы, бизнесы, боксы, юзеры
- Высшие модеры / овнер: `/give` `/take` `/eco`, всемирный шоп/работы/бизнесы/боксы с сайта

`/pay`, `/dep`, `/with`, `/flip`, `/take`, `/btc` принимают `all`.

Префикс (`!collect daily`, `!pay all`) включается на сервере через сайт или `/settings prefix`. Если ответить на сообщение — цель подставится сама.

## Запуск

Нужен Node.js 18+.

```bash
cp .env.example .env
npm install
```

В `.env`:

| Переменная | Зачем |
| --- | --- |
| `DISCORD_TOKEN` | токен бота |
| `CLIENT_ID` | Application ID из Discord Developer Portal, нужен для `npm run deploy` и сайта |
| `CLIENT_SECRET` | OAuth2 Secret приложения — без него сайт не пустит в Discord |
| `OWNER_ID` | Discord ID владельца. Если пусто, бот берёт владельца приложения |
| `PORT` | HTTP для сайта и health-check, по умолчанию `3000` |
| `PUBLIC_URL` | можно не ставить на Render — берётся сам. Иначе публичный адрес панели без слэша |
| `PREFIX` | префикс текстовых команд, по умолчанию `!` |
| `DATABASE_PATH` | файл экономики. По умолчанию `data/economy.sqlite`. На хостинге поставь путь на диск, который не стирается при деплое |

Privileged Gateway Intent **Server Members Intent** и **Message Content Intent** должны быть включены в портале — без первого не работают приветствия, без второго не работают префикс-команды.

```bash
npm run deploy   # один раз: публикует глобальные слэш-команды
npm start
```

`GET /health` отвечает `{ "ok": true }` сразу, без sqlite и сессий — для внешнего крон-пингера.
Сайт крутится на том же `PORT`.

## Сайт с настройками

Логин через Discord. Справа выпадающая панель: сервер, команды, кастомные слэш, ивенты. Высшие модеры — юзеры и всемирный шоп/работы/бизнесы/боксы.

Сессия в sqlite, 30 дней. После рестарта Render заново логиниться не надо.

XP за сообщения копится в памяти и раз в полторы минуты пишется пачкой. За уровень падают монеты. Магаз сервера и всемирный — разные.

Теги в редакторе зависят от модуля: `{user.id}` `{guild.id}` `{balance}` `{level}` `{xp}` `{business.count}` и остальные, там список.

### Красивая ссылка

`blackhole-d7h5.onrender.com` даёт сам Render, из кода его не сократить.

- Свой домен: Render → сервис → Settings → Custom Domains, например `bot.твойдомен.ru`. Потом `PUBLIC_URL=https://bot.твойдомен.ru` и в Discord Redirects `https://bot.твойдомен.ru/oauth/callback`.
- Или переименуй Web Service в Render в `blackhole` — если имя свободно, будет `https://blackhole.onrender.com`.

### Нагрузка

Один процесс + SQLite нормально тянет обычный сервер и панель. Не крути несколько инстансов Render на одной базе.

Бесплатный Render засыпает без запросов ~15 минут, первый заход после сна тупит. Чтобы сайт не спал — план Starter или внешний пинг на `/health`.

Экономика по умолчанию всемирная (старые балансы на месте). На сервере можно включить гильдийный кошелёк, локальные работы/бизнесы/магазин/боксы и штрафы за простой. Пассив бизнесов считается по `last_revenue_collect`, без таймеров. `/flip` режет ставку, `/rob` режет куш. Деньги и дроп боксов крутятся в `db.transaction()`.

Сайт: тумблеры экономики, редакторы работ/бизнесов/боксов, цветные роли в магазине (HEX строго `#RRGGBB`). Владелец бота может поставить сервер на паузу.

Новый Discord-сервер сразу пишется в sqlite при заходе бота. Welcome/leave настраиваются на сайте, файла `servers.json` больше нет.

Ссылка на панель — не из Discord. Это адрес сайта бота, вида `https://имя.onrender.com` (не `dashboard.render.com`).

На Render сверху на странице сервиса кликабельный `….onrender.com`. Бот подхватывает его сам: в логах `Сайт: https://….onrender.com`, в `/help` тоже.

В Discord → OAuth2 → Redirects вставь этот адрес + `/oauth/callback`, например `https://имя.onrender.com/oauth/callback`. В env нужен ещё `CLIENT_SECRET`.

Видеть и менять настройки можно только на серверах, где ты админ / владелец / Manage Server. Если бота ещё нет — кнопка инвайта.

## Экономика

Один пользователь — один баланс на всех гильдиях, где стоит бот. Либо изолированный кошелёк сервера, если включить гильдийный режим.

| Действие | Кулдаун |
| --- | --- |
| `/collect` ежедневка | 24 часа, 300–1100 монет |
| `/collect` работа | 45 минут |
| `/collect` преступление | 2 часа, можно уйти в минус |
| `/rob` | 90 минут, только наличные, у цели минимум 50 |

`/box` открывает лутбоксы. На сайте можно собрать таблицу дропа: монеты, свитки профессии, буст бизнеса, другой бокс, предмет, цветная роль.

`/top` листается кнопками ◀ ▶, отдельная кнопка переключает деньги и уровень.

`/settings prefix` или сайт — только слэш или префикс+слэш на этом сервере. Префикс можно сменить (например `bh!`). По умолчанию префикс включён.

`/give`, `/take` и `/eco` — только владелец и высшие модераторы. Обычных модеров ставит `/mod add`, высших — владелец через `/mod add rank:Высший модератор`. Серверные модеры крутят только локальную экономику.

База — SQLite (`better-sqlite3`) в `data/economy.sqlite`. Старый файл `Database/database.sqlite` при старте копируется туда, балансы не обнуляются. На остановке WAL сбрасывается в основной файл.

Если бот на Render / Railway / Docker без тома — диск пустой после деплоя, экономика снова с нуля. Повесь volume и пропиши `DATABASE_PATH`, например `/data/economy.sqlite`. В логе при старте будет строка `Экономика: ...` — это актуальный путь.

## Тесты

```bash
npm test
```

Проверяются `transfer`, `rob`, `flip`, боксы, пагинация топа, `collect`, префикс, настройки гильдии, кастом-эмбеды, ивенты, шоп, ранги модеров и страницы панели.

## Структура

```
Commands/   слэш-команды
Buttons/    кнопки (авторизация и топ)
Events/     ready, join, leave, логи, prefix
Database/   SQLite: экономика, гильдии, кастом-команды, боксы
Web/        OAuth и панель модулей
Utils/      staff, магазин, collect, префикс, автомод
```

## Права бота

Минимум: отправка сообщений, эмбеды, Manage Roles (автороль, `/authpanel`, цветные роли), Manage Messages и Manage Channels (`/clear`, `/slowmode`).
